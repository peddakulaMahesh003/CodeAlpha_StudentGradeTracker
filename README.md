# CodeAlpha Student Grade Tracker

A simple Java-based application to manage and track student grades. It allows users to add student details, view grades, search for specific students, and calculate average statistics.

## Features
- Add student names and grades
- Calculate average, highest, and lowest scores
- Search and view student records

## How to Run
1. Make sure you have Java installed.
2. Compile the project:
   ```bash
   javac Main.java
   ```
3. Run the application:
   ```bash
   java Main
   ```
